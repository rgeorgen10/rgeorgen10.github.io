Arch Linux Install Assistant

Linux installation automation

Installing Arch Linux can be a long winded task, even for experienced users. This project was an attempt from me to simplify this process. This script can be downloaded into the live ISO environment and assists with partitioning, base install, system configuration, and even installing an AUR manager and desktop environments.

NVIDIA Power Management Script Configuration

Graphics power management

Setting up NVIDIA Optimus on Linux systems is a complex task and took me many hours to figure out. To solve this, I made a Python script that adds the necessary configuration files to the system. With this configuration, the system should prioritize the integrated GPU and only use the dedicated GPU when needed.
